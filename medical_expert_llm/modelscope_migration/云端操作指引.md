# ModelScope 云端训练操作指引

> 项目：基于大模型微调的医疗专家 · 云端迁移方案
> 数据集：`Huahai123654/medical-cot-zh`（私有，已上传）
> 基座模型：`Qwen/Qwen2.5-7B-Instruct`（云端 Hub 直接拉取，**无需上传本地 15GB 权重**）
> 迁移原因：本地 RTX 4060 Laptop 8GB 全量训练约需 30 小时且多次中断，云端 GPU 实测约 4 小时跑完全量
> **当前状态**：全量训练已于 2026-09-10 完成，权重已回迁本地；本指引保留作**流程复现**用。实测数据与排障记录见 `docs/云端训练工作日志.md`

## 一、创建 Notebook（免费 GPU 实例）

1. 浏览器登录 [modelscope.cn](https://modelscope.cn)，账号与上传数据集一致（`Huahai123654`）
2. 顶部菜单进入「我的Notebook」→「启动实例」
3. 选择配置：
   - **GPU 规格**：选择标注「免费」额度的 GPU 实例（常见为 A10 24GB 等规格；7B QLoRA 微调 24GB 显存绰绰有余）
   - **镜像**：PyTorch 2.x + CUDA 12.x 系列（如 `pytorch:2.1.2-gpu`，具体以页面可选为准）
4. 点击启动，等待实例进入「运行中」，点击进入 JupyterLab

**免费实例注意事项**：

| 事项 | 说明 |
|---|---|
| 时长限额 | 免费额度通常有每日时长限制，**训练前再启动实例**，平时关机节省额度 |
| 释放风险 | 实例停止/释放后磁盘内容清空，**训练产物（LoRA 权重）完成后第一时间推送到 Hub**（第 5 步脚本做的事） |
| 训练时长 | 全量 19134 条 × 1 epoch 实测 11.9 秒/步 × 1,196 步 ≈ **4 小时**（本地同规模约 30 小时）。**迁移前「约 2 小时」为预估，偏乐观**，请预留足够免费时长或准备断点续训 |

> **训练框架版本**：脚本参数按 **ms-swift 4.5.3** 源码逐项核对（`tuner_type` / `report_to` / `resume_from_checkpoint` 等）。若环境自动安装到更高版本，需重新核对参数，详见 `docs/云端训练工作日志.md` 第六节。

## 二、上传迁移脚本到 Notebook

在本地 `medical_expert_llm\modelscope_migration\` 目录下有：

| 文件 | 作用 |
|---|---|
| `01_upload_dataset.py` | 数据集上传（已在本地执行完成，云端无需再跑） |

**上传方式**：JupyterLab 左侧文件树 → 右键根目录 → **Upload**，选中上述 `.sh` 文件逐个上传。

## 三、初始化环境（执行 02_setup_env.sh）

1. JupyterLab 顶部菜单 **File → New → Terminal** 打开终端
2. 先设置 Token（推荐用环境变量，不写入任何文件）：
   - 在终端执行 `export MODELSCOPE_API_TOKEN='ms-你的令牌'`，不要直接把明文写进脚本
   - 若沿用脚本内占位值，找到 `MODELSCOPE_API_TOKEN="ms-请替换成你的令牌"` 临时替换，**用完立即删除**
3. 执行：

```bash
bash 02_setup_env.sh
```

脚本依次完成（幂等，可重复执行）：

1. 安装 ms-swift（自动带上 transformers / peft / datasets / accelerate），随后确认版本为 4.5.3
2. Token 登录 + 写入 `~/.bashrc`（之后新开终端自动带 Token；**实例释放或共享前请清理该行**）
3. 自检 GPU、显存、各依赖版本
4. 下载私有数据集到 `~/medical_data/` 并校验条数（train 19134 / val 1007）

全部显示 `[OK]` 即环境就绪。

---

## 四、启动训练

环境就绪后直接执行（详见 `03_train_cloud.sh` 内注释）：

```bash
bash 03_train_cloud.sh            # 全量训练（首次会自动下载基座模型约 15GB）
bash 03_train_cloud.sh resume     # 中断后断点续训
```

监控方式：终端实时输出 loss；TensorBoard 日志在输出目录的 `runs/` 下，
JupyterLab 中可另开终端用 `tensorboard --logdir <输出目录> --host 0.0.0.0` 查看。

**已完成的实测结果（2026-09-10）**：1,196 步 / 约 3.95 小时 / 全程无 OOM / 产出 154.1 MB LoRA 适配器（详见 `docs/云端训练工作日志.md` 第五、七节）。

## 五、训练完成后推送模型

```bash
bash 05_push_model.sh
```

该脚本用 `swift export` 合并 LoRA 权重，推送为你的 ModelScope 模型仓库，
并自动生成模型卡片（README.md：模型描述、训练数据集、训练参数、用法示例）。

**当前进度**：LoRA 适配器已推送至 `Huahai123654/medical-expert-lora`（公开）；15GB 合并完整模型为**可选项**，尚未推送，本地演示不依赖它。

## 常见问题排查

| 现象 | 处理 |
|---|---|
| 自检报 "GPU 不可用" | 启动实例时没选 GPU 镜像：停止实例 → 重新启动并选择 GPU 规格 |
| 数据集下载 401 / 无权限 | Token 未生效：`export MODELSCOPE_API_TOKEN='ms-xxx'` 后重试；或令牌过期，去网页重新创建 |
| 磁盘不足（df -h 查看） | `pip cache purge` 清理；确认只保留必要文件 |
| 实例中途被释放 | 重新启动 → 重跑 `02_setup_env.sh`（数据重新拉，很快）→ `03_train_cloud.sh resume` 从最近 checkpoint 续训 |
| 显存不足（CUDA OOM） | `03_train_cloud.sh` 内置自动降级重试（batch 减半、累积步数翻倍）；仍失败则手动编辑脚本顶部的 BATCH_SIZE |
| 参数报「未知参数」 | ms-swift 版本漂移：确认 4.5.3，按 `docs/云端训练工作日志.md` 第六节逐项校正 |
