设计系统规范

先统一语言，再画界面。以下 Token 是原型与后续开发的唯一事实来源，任何新组件都必须从这里取值，避免视觉碎片化。

01设计原则：面向「焦虑中的非专业用户」

安心优先

大字号（正文 16px）、1.85 行高、低饱和蓝与大量留白，降低医疗场景的天然紧张感；免责声明显眼但不恐吓。

推理透明

「医学推理」与「专业解答」双段分离：推理默认可折叠，结论永远直接可读，兼顾信任感与阅读效率。

零学习成本

沿用主流对话产品肌肉记忆：历史会话在左、输入框固定底部、Enter 发送、示例一键提问。

可访问性内建

WCAG AA 起步：正文对比度 ≥ 4.5:1、全键盘可达、44px 触控目标、尊重减少动效偏好。

02色彩系统 · 极简蓝调

单一主色 + 中性灰承载 90% 界面；语义色只用于状态，不做装饰。主色 #2563EB 在白底上对比度 5.17:1，满足 AA。

06可访问性清单（WCAG AA）

  • 正文与背景对比度 ≥ 4.5:1，占位符与禁用色不承载关键信息。
  • 全部功能可键盘完成：Tab 顺序符合视觉顺序，焦点环 2px 主色 + 2px 偏移。
  • 可点击目标最小 44×44px；图标按钮带 aria-label；滑杆绑定 label。
  • 推理折叠使用原生 details/summary，屏幕阅读器可直接朗读展开状态。
  • 尊重 prefers-reduced-motion，关闭全部非必要动画；流式区域建议 aria-live="polite"。
  • 正文字体可随浏览器放大至 200%，布局使用相对单位不截断。
